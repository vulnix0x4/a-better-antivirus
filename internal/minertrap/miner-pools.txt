# The miner trap's list of mining pools (A Better Antivirus).
#
# With the miner trap on, each name below, and every name under it, leads to
# ABA's fake mining pool on this PC instead of the real one (see
# internal/minertrap/pools.go). Nothing else is redirected.
#
# One name per line; "#" starts a comment. It holds the public pools hidden
# miners are configured with (most of them mine Monero, whose RandomX
# algorithm runs well on ordinary processors), from public analyses of miner
# malware and the pools' own connection guides. The pools' websites don't open
# while the trap is on, so a name is listed only where the whole domain is a
# pool's; where a big company's domain has a mining part, only that part is.
#
# This file is a release file of its own, next to aba.exe, and it is in the
# signed SHA256SUMS.txt like the program. It is plain data on purpose: compiled
# into the program, these names made antivirus engines take ABA for a miner.
# The first name is the one `aba miners test` looks up (as pool.<name>).
